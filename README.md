# 📈 디스코드 주식 게임 봇

디스코드 서버에 봇으로 초대해서 친구들과 즐기는 **모의 투자 게임**입니다.
**실제 시세**(한국·미국 주식, 코인, ETF, 금, 환율)로 현물·신용·미수·선물·옵션을 거래할 수 있어요.
계좌는 봇이 들어간 **모든 서버에서 공용**이라, 어느 서버에서 거래해도 같은 계좌를 씁니다.

## 거래 상품 (실제 시세, 총 148종목)

전체 목록은 `src/assets.js`에 있고, 한 줄씩 추가·삭제할 수 있어요.

- **24시간 거래 가능.** 실제 장이 닫힌 상품(💤)은 **마지막 종가**로 거래돼요.
- 코인·선물·지수는 소수 단위(예: `0.01`)로도 거래돼요. 해외 상품은 실시간 환율로 원화 환산.
- 코인은 1분마다, 나머지는 장중 3분·장 마감 후 30분마다 갱신. 요청이 몰리지 않게 1분에 최대 20종목씩 나눠서 받아요.
- 종목 이름은 입력할 때 **자동완성**으로 골라요. (예: `삼성`, `AAPL`, `코덱스`, `원유`)

## 게임 방법 — `/주식` 하나로 끝

채팅창에 **`/주식`** 을 입력하면 나만 보이는 **주식 터미널**이 열리고, 이후는 전부 버튼·메뉴·팝업으로 조작해요.
(`/주식 종목:삼성전자` 처럼 종목을 지정하면 그 종목 화면으로 바로 열려요.)

| 화면 | 할 수 있는 것 |
|------|---------------|
| 🏠 홈 | 순자산·수익률, **오늘의 시장 히트맵**, 분류 메뉴, 🔍 검색, 💼 내 자산, 📋 포지션, 🏆 랭킹, 🎁 출석 |
| 📂 종목 목록 | **시세판 이미지**(아이콘·미니차트·등락 배지, 20개씩 페이지), 메뉴에서 종목 선택 |
| 📈 종목 화면 | **차트 이미지 (1일·1주·1달·1년)**, 내 보유 현황, 🛒 매수(현금·신용·미수) · 💸 매도 · ⚡ 롱/숏 · 🎯 옵션 |
| 🧾 주문창 | 버튼으로 수량·방식·레버리지·행사가를 고르면 **결제 금액·대출·거래 후 현금/보유·손익·청산가**를 미리 보여 주고, **[실행]을 눌러야 체결** |
| ✅ 체결 영수증 | 거래 전 → 후 현금·보유·대출·순자산 비교 |
| 💼 내 자산 | 순자산, **자산 구성 막대그래프**, 보유 종목별 손익과 [보기] 버튼, 파산 신청 |
| 📋 포지션 | 선물·옵션·대출 목록, 골라서 정리(확인 버튼), 💳 대출 상환 |
| 🏆 랭킹 | 전체 서버 / 이 서버 순자산 TOP 10 |

- 수량은 [+1주]·[+10주]·[25%]·[최대] 같은 버튼으로 고르고, 원하면 ✏️ **직접 입력**(`10`, `0.01`, `절반`, `30%`, `10만원`)도 돼요. 직접 입력해도 바로 체결되지 않고 미리보기로 돌아와요.
- 선물은 청산가와 "가격이 1%·5% 움직이면 얼마"를, 옵션은 손익분기점과 만기 때 가격별 손익표를 보여 줘요.
- 📢 **채널에 공유** 버튼으로 차트·내 자산·랭킹을 채널에 공개로 올릴 수 있어요.

## 거래 규칙

- **시작 자금** 1,000,000원 · 현물·옵션 수수료 0.15% · 선물 수수료 0.05%(포지션 규모 기준)
- **신용매수**: 본인 돈 50% + 대출 50%, 연 9% 이자
- **미수매수**: 증거금 40%만 내고 매수, 2일 안에 결제. 결제일에 현금이 모자라면 **반대매매**
- **대출 한도** 순자산 × 1.5 · **담보비율** (총자산 ÷ 대출) 140% 미만이면 **반대매매**
- **선물**: 손실이 증거금의 90%에 닿으면 **강제청산** (청산가는 진입 시 안내)
- **옵션**: 블랙-숄즈 공식으로 가격 계산. 손실은 산 가격까지만. 만기에 자동으로 내재가치 정산
- 반대매매·강제청산·옵션 만기 정산은 **DM으로 알림** (DM을 허용한 경우)

## 구조 — Railway 부하 최소화

```
GitHub Actions (15분마다)            GitHub Pages                  Railway (봇)
 ├ 야후·업비트에서 시세·차트 데이터 ─▶ data/quotes.json  ◀── 3분마다 1번 읽기
 └ 차트·시세판·히트맵·아이콘 그리기 ─▶ charts/*.png     ◀── 디스코드가 직접 가져감
                                                           ├ 코인 시세: 업비트 1분마다 1번
                                                           └ 버튼 처리·계좌 계산만
```

- 차트·시세판·히트맵·종목 아이콘은 GitHub가 그리고 디스코드가 직접 가져가서 **Railway는 이미지를 만들지도 보내지도 않아요.**
- 화면은 디스코드의 새 메시지 레이아웃(Components V2: 카드·구역·갤러리)으로 그려요.
- 화면(버튼·메뉴·팝업)은 디스코드가 그려요. 봇은 버튼 신호만 처리해요.
- 주식·ETF·선물·금·환율 시세는 Pages의 파일 하나로 받아요. Pages가 45분 넘게 멈추면 그때만 야후에서 직접 받아요.

### GitHub Pages 켜기 (처음 한 번)

1. GitHub 저장소 → **Settings → Pages**
2. **Build and deployment → Source** 를 **GitHub Actions** 로 선택
3. **Actions** 탭 → **시세·차트 생성** → **Run workflow** 로 처음 한 번 실행
4. 몇 분 뒤 `https://<깃허브아이디>.github.io/discord-stock-bot/` 에 시세·차트 목록이 보이면 성공

> 저장소 이름이나 계정이 다르면 Railway 변수 `PAGES_URL` 에 위 주소를 넣어 주세요.
> GitHub는 60일 동안 저장소에 변화가 없으면 예약 실행을 멈춰요. 그럴 땐 Actions 탭에서 다시 켜면 돼요.

## 1. 디스코드 봇 만들기

1. https://discord.com/developers/applications → **New Application**
2. 왼쪽 **Bot** 메뉴 → **Reset Token** → 토큰 복사 (절대 공유 금지!)
3. Privileged Gateway Intents는 **켤 필요 없음**

## 2. 실행

```bash
npm install
cp .env.example .env   # .env 파일을 열어 DISCORD_TOKEN 입력
npm start
```

실행하면 콘솔에 **초대 링크**가 출력됩니다. 그 링크로 봇을 서버에 추가하세요.
(직접 만들려면: `https://discord.com/oauth2/authorize?client_id=애플리케이션ID&scope=bot+applications.commands&permissions=18432`)

> 💡 처음 테스트할 때는 `.env`에 `GUILD_ID`(서버 ID)를 넣으면 명령어가 즉시 뜹니다.
> 비워두면 전역 등록이라 모든 서버에서 쓸 수 있지만 반영에 시간이 걸릴 수 있습니다.

## 3. 24시간 켜두기 (Railway)

1. Railway에서 **New Project → Deploy from GitHub repo** → 이 저장소 선택
2. **Variables** 에 `DISCORD_TOKEN` 추가
3. 데이터 유지: **Volume** 을 추가하고(예: `/data` 에 마운트) 변수 `DATA_DIR=/data` 설정
   — 볼륨이 없으면 재배포 때 계좌 데이터가 초기화됩니다.

## 설정값

| 변수 | 기본값 | 설명 |
|------|--------|------|
| `DISCORD_TOKEN` | (필수) | 봇 토큰 |
| `GUILD_ID` | 없음 | 특정 서버에만 명령어 즉시 등록 |
| `TICK_SECONDS` | 60 | 코인 시세 갱신·위험 점검 주기(초), 최소 15 |
| `YAHOO_REFRESH_SECONDS` | 180 | (Pages가 멈췄을 때만) 야후 직접 조회 주기(초) |
| `YAHOO_PER_TICK` | 20 | (Pages가 멈췄을 때만) 한 틱에 야후에 요청하는 최대 종목 수 |
| `DATA_DIR` | `./data` | `stock_game.json` 저장 위치 |
| `PAGES_URL` | `https://ahn493844-cmyk.github.io/discord-stock-bot` | 시세·차트를 가져올 GitHub Pages 주소 |

종목 추가·변경은 `src/assets.js`의 `ASSETS`, 시작 자금·수수료·레버리지·대출 규칙은 `src/game.js` 상단 상수를 고치면 됩니다.

## 시세가 안 들어올 때

Railway **Deploy Logs**에 `[price] 시세 갱신(pages) 성공 N · 실패 M` 줄이 찍힙니다.
- `(pages)` 면 정상 — GitHub Pages에서 받는 중이에요.
- `(yahoo)` 면 Pages가 멈춘 상태예요. GitHub **Actions** 탭에서 **시세·차트 생성** 실행 기록에 빨간 ✗가 있는지 확인하세요.
- Actions 로그의 `시세 N/148 · 차트 N장 · 실패 N` 줄에서 실패한 종목과 이유(예: `HTTP 429`)를 볼 수 있어요.
